# 🧩 遊び方 ― FILEuS（ファイルアス）

## ！戦闘パートがまだ未実装なため現状遷移したら終了です！

## 🖥️ 概要

このゲームは **PC内のファイルをドラッグ＆ドロップしてキャラを育てる、育成＆バトルゲーム** です。  
ファイルを読み込ませて「修正パッチ」を育て上げ、侵略してきた **ウイルス（ボス）** と戦いましょう。



## 🧬 育成パート

キャラには以下の **5つのパラメーター** と、1つの特殊ゲージ「メモリゲージ」が存在します。

| パラメータ | 説明 | 他ゲームでの例え |
|-------------|------|------------------|
| 信頼性 | システムの安定度 | HP（体力） |
| 可用性 | 動作の持続力 | MP（魔力） |
| 保守性 | 自己修復や回復力 | 回復力 |
| 保全性 | 攻撃や破壊耐性 | 攻撃力 |
| 安全性 | エラー・状態異常への強さ | 防御力 |
| メモリゲージ | システムの負荷度 | ―（MAXでゲームオーバー） |

### 📁 ファイルによる成長
- ファイルの **拡張子によって上がりやすい／下がりやすいパラメータ** が異なります。  
  例：  
  - `.txt` → 信頼性↑ / 保全性↓  
  - `.png` → イベント確定 
  - `.exe` → 保全性↑ / 安全性↓  
  （※更新日など、隠された要素も反映されているかも……）

- **同じファイルを2回読み込むことはできません。**  

### ⚙️ メモリゲージの管理
- メモリゲージが **MAXになると即ゲームオーバー**。  
- イベント時の「トラブル発生率」も上昇するため、できるだけ低く保ちましょう。  
- `.zip` などの **圧縮ファイルを読み込むとメモリゲージが大幅に回復** します。

### 💾 スキルファイルの獲得
- 時折発生するイベントで「**スキルファイル**」を獲得できます。  
- スキルファイルは実際の **ゲームフォルダ内に書き出される実データ** です。  
- 次の「戦闘パート」で使用可能になります。



## ⚔️ 戦闘パート

### 🎮 基本ルール
- 育成中に得た **スキルファイル** を使用して戦います。  
- 1ターンは  
  - 敵の行動枠 × 2  
  - プレイヤーの行動枠 × 2  
 で構成されています。

### 📂 行動セットの方法
1. プレイヤーの行動枠（スロット）にスキルファイルを **ドラッグ＆ドロップ** します。  
2. 行動が確定し、ターン終了時に実行されます。  

### ⚠️ スキルの消費
- スキルファイルは **使い切り** です。  
  一度使うとフォルダからも削除されるため、  
  使用タイミングを慎重に選びましょう。



## 💡 ヒント

- 育成中にどの拡張子を読み込むかで戦略が大きく変化します。  
- メモリゲージ管理とスキルファイル獲得のバランスが勝敗を左右します。  
- 圧縮ファイルは命綱。困った時の回復手段として覚えておきましょう。
